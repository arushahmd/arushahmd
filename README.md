## Selected Work

### [Restaurant Voice AI](https://github.com/arushahmd/restaurant-voice-ai)

Real-time conversational ordering system combining **Twilio Media Streams, Deepgram STT/TTS, custom NLU, Redis-backed sessions, and deterministic state-machine orchestration**.

**Signal:** real-time AI · conversational systems · backend architecture · state management · observability · deployment

### [Multi-Head Intent Classification](https://github.com/arushahmd/multihead-intent-classification)

Transformer-based hierarchical intent classifier with **independent main/sub-intent heads, leakage-resistant splitting, reproducible experiment manifests, evaluation, offline tests, and CI**.

**Signal:** NLP · transformers · evaluation · reproducibility · ML engineering

### [DataMatrix Reconstruction](https://github.com/arushahmd/datamatrix-reconstruction)

Reproducible classical computer-vision pipeline for recovering degraded DataMatrix symbols with explicit inference rejection and deterministic synthetic evaluation.

- Exact decode improved from **28/35 to 33/35** on the committed synthetic benchmark
- Grid shape was exact for **34/34 accepted cases**

**Signal:** computer vision · image processing · benchmarking · failure handling · reproducibility

### [Controlled Mini-Batch Ordering for Instruction Fine-Tuning](https://github.com/arushahmd/llm-batching-research)

Empirical study of mini-batch composition and training-example order for instruction fine-tuning across **54 reviewed runs** using Flan-T5, LoRA, FAISS, and multi-seed evaluation.

**Signal:** LLM fine-tuning · experiment design · multi-seed evaluation · research methodology
